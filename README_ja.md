# File Obscura

許可リストモードでファイルを保護します。許可リストに含まれていないファイルは自動的にマスクされ、確認後に表示できます。

この拡張機能は、ライブコーディングやストリーミング配信中に`.env`ファイルに含まれるトークンや秘密のアルゴリズムを誤って公開することを防ぐために作成されました。設計は使いやすさよりも安全性を重視しています。

## インストール

1. VS Codeを開く
2. 拡張機能ビューを開く（`Ctrl+Shift+X` / `Cmd+Shift+X`）
3. "File Obscura"を検索
4. インストールをクリック

または、コマンドラインからインストール：
```bash
code --install-extension miyazakiyuma.file-obscura
```

## 機能

- **自動ファイルマスク**: 許可リストに含まれていないファイルは、開いたときに自動的にマスクされます
- **許可リストベースの保護**: 明示的に許可されたファイルのみが通常通り表示されます
- **一時的な表示**: マスクされたファイルは確認後に表示でき、タイムアウト後に自動的に再マスクされます
- **一時的なマスク機能のオン/オフ**: 右下のステータスバーからワンクリックでマスク機能を一時的に無効化できます。次回起動時は自動的に有効に戻ります
- **Globパターン対応**: globパターンを使用した柔軟なファイルマッチング
- **ワークスペーススコープ設定**: プロジェクトごとに設定可能

## 使い方

1. **許可リストを設定**: 設定の`fileObscura.allowlist`にファイルまたはパターンを追加
   - 例: `["*.js", "*.ts", ".env.local"]`
   
2. **ファイルを開く**: 許可リストに含まれていないファイルは、内容の代わりにマスクされたビューが表示されます

3. **ファイルを表示**: 内容を確認する必要がある場合は「ファイルを表示」ボタンをクリック
   - ファイルは一時的に表示されます
   - タイムアウト期間（デフォルト: 5分）後、ファイルが閉じられていれば自動的に再マスクされます

4. **許可リストに追加**: マスクされたビューの「許可リストに追加」ボタンを使用して、ファイルを永続的にマスクから除外

5. **一時的にマスク機能を無効化**: 右下のステータスバーに表示される「🔒 有効」ボタンをクリックすると、マスク機能を一時的に無効化できます
   - 無効化中は、すべてのファイルが通常通り開けます
   - ボタンは「🔓 無効」に変わります
   - 再度クリックするとマスク機能が再有効化されます
   - 有効化すると、開いているマスクすべきファイルが自動的にマスクビューに切り替わります
   - **注意**: この設定は一時的なもので、VS Codeを再起動すると自動的に有効に戻ります

### 使用例

- **ライブコーディング配信**: APIキーを含む`.env`ファイルを保護
- **画面共有**: 秘密のアルゴリズムを誤って表示することを防止
- **コードレビュー**: 機密情報を含む設定ファイルをマスク

## 設定

### `fileObscura.enabled`
- **型**: `boolean`
- **デフォルト**: `true`
- **説明**: マスク機能をグローバルに有効または無効にします

### `fileObscura.allowlist`
- **型**: `string`の配列
- **デフォルト**: `[]`
- **スコープ**: リソース（ワークスペース）
- **説明**: マスクから除外するファイルまたはglobパターンのリスト。これらのパターンに一致するファイルは通常通り開きます。空の場合は、すべてのファイルがマスクされます。
- **例**:
  - `["*.js", "*.ts"]` - すべてのJavaScriptファイルとTypeScriptファイルを許可
  - `["src/**/*", ".env.local"]` - `src/`ディレクトリ内のすべてのファイルと`.env.local`ファイルを許可
  - `["**/*.env"]` - すべての`.env`ファイルを許可

### `fileObscura.revealTimeout`
- **型**: `number`
- **デフォルト**: `5`
- **最小値**: `1`
- **説明**: 表示されたファイルのタイムアウト（分単位）。この時間経過後、ファイルが閉じられていれば自動的に表示リストから削除されます。
